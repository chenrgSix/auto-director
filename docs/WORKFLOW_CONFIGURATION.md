# 工作流配置指南

## 可直接使用的 codex 工作流包

[`workflow_examples/codex_8gb`](../workflow_examples/codex_8gb/README.md) 提供 Z-Image 文生图、H3 图生图、H3 首帧及首尾帧视频四套原生 ComfyUI 画布、API 图和完整绑定配置。针对已安装的 INT8 / FP8 / NVFP4 模型准备，无需 AI 识别。工作流包按需导入，不随重启自动恢复；设置默认项仍由用户选择。

C48 针对实际计算路径优化：视频在 LoRA 与 Guider 之间接入原生 `ModelAttentionBackend`，选择 `comfy kitchen attention`；Z-Image 使用整图 VAE 解码。图生图保留实测更合适的基础 12 步。用户 ComfyUI 的「工作流」列表已保存同名 `codex-` 画布；独立运行前选择输入图片。视频 attention 可在画布节点或 AutoDirector 参数页切回 `pytorch attention`，不会改变服务器全局设置。样例速度与验收范围见 C48 记录。

本次 8GB 实机试跑使用 640×384。正常创作由系统继续按比例/显存预算分配尺寸，例如 H3 横屏低显存策略为 672×384；没有承诺任意自定义尺寸或时长都能运行。H3 图生图使用匹配 FL2VA 权重的节点，适合保留原图结构的小幅变化，输出生成的最后一帧，避免选回锁定的参考帧。

## 没有秒数，只有 length / num_frames

把「视频长度（秒或帧）」绑定到实际帧数字段，「时长单位」选「帧 · 按 FPS 转换」。帧数 = 秒数 × FPS；时长 = 帧数 ÷ FPS。普通整数帧数用倍数 1/偏移 0，4n+1 用 4/1，MiniMax H3 的 17n+5 用 17/5。仅当模型要求固定生成时钟时填写「固定生成帧率」，例如 H3 的 24，并将保存节点的 fps 绑定为「视频帧率」。

「首尾帧-MiniMax-真」示例：length=39、fps=24 只有约 1.63 秒。正确绑定后导演规划 5 秒会自动写入 length=124、fps=24，得到约 5.17 秒原始素材，拼接按 5 秒时间线裁剪。最大单镜时长仍填写 5 秒，不能用一个固定 length 代替自动换算。

新导入的工作流不会继承另一份工作流的帧数设置。即使把最大时长设为 6 秒，MiniMax H3 仍需配置 17/5/24；沿用通用的 4/1 且未固定帧率，可能与节点步长冲突，导致实际可用上限低于填写值。「minimax-h3-首尾帧-质量」已按此修正，5 秒对应 124 帧。


打开“工作流”，在左侧选中要修改的工作流。右侧顶部显示名称和生成用途；页签下的“保存配置”会一直显示，修改后可“取消修改”恢复上次保存内容。

## 输入与输出

为每个必填用途选择 JSON 中的实际字段。选项包含 **节点标题 · 字段（节点 ID）· 当前值**，可用文件名区分两个加载图片节点。已经用于其他用途的字段不可重复选择。

- 文生图：选择接收画面描述的字段和保存图片的输出节点。
- 图生图：另选参考图片输入。
- 首帧视频：选择画面描述、起始画面、镜头时长及视频输出。
- 首尾帧视频：还需选择结束画面。

时长字段接收秒数时选“秒 · 直接使用”；接收帧数时选“帧 · 按 FPS 转换”，并填写模型要求的倍数与偏移，例如 `4n+1`。负面提示、尺寸等可通过“添加其他用途”增加，只绑定工作流实际使用的输入。

不确定字段含义时，可以展开“让 AI 帮忙识别绑定”。AI 建议需确认；失败时仍能手动配置，导入无需等待 AI 或 ComfyUI。

## 模型与参数

搜索模型名、参数名或节点 ID，例如 `sampler`、`steps`、`137`。在对应节点下修改值后保存；检查过依赖的字段会显示 ComfyUI 返回的可选项和范围。

参数下方分别列出本字段与下游输入的限制，同一个值必须同时满足。例如整数节点本身允许 688，但下游视频高度要求从 32 起、步长 32，应使用 672 等合法值。创作高级覆盖也遵守这些限制；不要只看整数节点自身范围。未显示下游约束时，可先“保存并检查依赖”获取当前 ComfyUI 元数据。

“恢复导入值”取消此字段的模板覆盖。标记为 AI、导演或系统自动填写的参数，在实际生成时会被自动值替换；创作页面的高级覆盖仍优先。展开“自动填写与覆盖规则”可管理自定义字段归属和创作覆盖权限。

## 检查与试跑

“保存并检查依赖”检查模型、节点和参数，不提交生成。错误旁的“去修改此参数”会打开对应字段；缺少节点或连线错误需在 ComfyUI 修正。

数值由整数节点传入时，下游报错会定位到可编辑的源参数。正式生成还会检查实际将用的模型/节点/参数；上传前先验证全部素材，再执行上传。已经提交的作业仍用原始快照恢复，重连不自动重提。

若显示“包含云端 API 节点”，即使 ComfyUI 在本地启动，相关节点仍可能要求云端账号或密钥。本地模型工作流与云端 API 工作流不能仅按名称区分。

输入输出完整后可以“设为默认”，只影响新建短片。真实生成需继续通过依赖检查；“保存并试跑”会使用测试描述、上传素材和所连接的 ComfyUI 提交任务。

## 原生声音提示词（C52）

在视频工作流编辑页将“原生声音提示词”设为“MiniMax H3 · 对白 / 旁白 / 环境声”，前提是此图已连接 H3 音频 VAE、音频解码和视频音轨输出。两套 codex H3 已启用；其他图默认使用普通视频提示词。

新 Idea 可写“人物说……”“中文旁白……”；分镜预览中的视频提示词显示实际原文台词与声音说明，允许编辑。更换设置保留已写剧本，需主动重新生成提示词才能为旧镜头加入声音，已有 MP4 不会自动补声。
