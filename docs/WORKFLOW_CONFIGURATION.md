# 工作流配置指南

打开“工作流”，在左侧选中要修改的工作流。右侧顶部显示名称和生成用途；页签下的“保存配置”会一直显示，修改后可“取消修改”恢复上次保存内容。

## 输入与输出

为每个必填用途选择 JSON 中的实际字段。选项包含 **节点标题 · 字段（节点 ID）· 当前值**，可用文件名区分两个加载图片节点。已经用于其他用途的字段不可重复选择。

- 文生图：选择接收画面描述的字段和保存图片的输出节点。
- 图生图：另选参考图片输入。
- 首帧视频：选择画面描述、起始画面、镜头时长及视频输出。
- 首尾帧视频：还需选择结束画面。

时长字段接收秒数时选“秒 · 直接使用”；接收帧数时选“帧 · 按 FPS 转换”，并填写模型要求的倍数与偏移，例如 `4n+1`。负面提示、尺寸等可通过“添加其他用途”增加，只绑定工作流实际使用的输入。

不确定字段含义时，可以展开“让 AI 帮忙识别绑定”。AI 建议需确认；失败时仍能手动配置，导入无需等待 AI 或 ComfyUI。

## 模型与参数

搜索模型名、参数名或节点 ID，例如 `sampler`、`steps`、`137`。在对应节点下修改值后保存；检查过依赖的字段会显示 ComfyUI 返回的可选项和范围。

“恢复导入值”取消此字段的模板覆盖。标记为 AI、导演或系统自动填写的参数，在实际生成时会被自动值替换；创作页面的高级覆盖仍优先。展开“自动填写与覆盖规则”可管理自定义字段归属和创作覆盖权限。

## 检查与试跑

“保存并检查依赖”检查模型、节点和参数，不提交生成。错误旁的“去修改此参数”会打开对应字段；缺少节点或连线错误需在 ComfyUI 修正。

若显示“包含云端 API 节点”，即使 ComfyUI 在本地启动，相关节点仍可能要求云端账号或密钥。本地模型工作流与云端 API 工作流不能仅按名称区分。

输入输出完整后可以“设为默认”，只影响新建短片。真实生成需继续通过依赖检查；“保存并试跑”会使用测试描述、上传素材和所连接的 ComfyUI 提交任务。
