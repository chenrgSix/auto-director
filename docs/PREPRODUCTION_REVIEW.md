# C58：制作前画面确认与多图参考

## 冻结目标

由《雨停之前》的参考图文字污染、道具漂移和错误目标帧暴露的问题改进项目。保留旧片、创作包版本和默认工作流，不自动重新生成旧媒体。

1. 参考图提示只使用视觉描述，排除声音、表演和结构化字段标签；道具有独立且可复用的参考身份。
2. 新建页面推荐分阶段制作：先确认参考图，再逐镜确认首尾关键帧，确认后才提交该镜视频。等待期间释放制作 Worker，网页和 MCP 均可检查、修改并继续。连续镜头依赖前镜真实尾帧。
3. 接入用户提供的 H3 多图参考能力，明确有序参考用途，未选择的可选输入不能提交占位文件；保留旧工作流必填输入语义。

## 验收与边界

- 旧 API / 创作包省略新开关时维持原流程，已完成短片不迁移。
- 确认绑定当前素材、提示目标和工作流配置；过期版本、重复请求冲突及通用继续入口不能绕过确认。修订保存历史资产，不删除文件。
- 隔离集成测试证明确认前视频作业为零、连续镜尾帧继承、局部修订与 MCP / 网页操作。
- 验证 H3 节点实际端口及可导入配置，完整本地门禁与浏览器验收单独记录。静态连线与合成媒体测试不代表真实画质或多图显存开销通过。
- 不改变完整源片段拼接、音频、未知远端作业恢复和现有用户参数优先级。
