## 完成定义

每个实现任务包含代码、适当测试、模块/接口/运行文档更新及独立 Git commit。T01 完成只能证明本地工程闭环；项目的真实生成验收必须通过 T02，不用模拟媒体代替。性能指标 §59 需要多次实跑统计，单个成功样本不能证明成功率。
