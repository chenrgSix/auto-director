# 开发任务与交付目标

## 冻结目标（2026-09-10）

依据原文 §2 P0、§57 Phase 1/2、§58：用户输入 Idea 与 5/10/15 秒目标时长，完成自动计划、Visual Bible、参考资产、首尾帧、ComfyUI 视频渲染、质检/局部重试、FFmpeg 合成与 MP4 下载。用户可导入 API JSON、配置绑定/参数、验证、试跑并设置默认工作流。

技术范围：本地优先，单用户、单 API 进程、单 ComfyUI、渲染并发 1；Python/FastAPI/SQLite，React/TypeScript/Vite，FFmpeg；LLM/VLM 走独立的 OpenAI-compatible JSON/vision 接口。真实模型与权重由用户环境提供。

## 完成定义

每个实现任务包含代码、适当测试、模块/接口/运行文档更新及独立 Git commit。T01 完成只能证明本地工程闭环；项目的真实生成验收必须通过 T02，不用模拟媒体代替。性能指标 §59 需要多次实跑统计，单个成功样本不能证明成功率。
